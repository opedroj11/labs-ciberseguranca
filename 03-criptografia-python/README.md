Laboratório de Criptografia Simétrica (Python)

Este projeto demonstra a implementação de criptografia simétrica utilizando a biblioteca nativa Fernet (baseada no padrão AES - Advanced Encryption Standard) em Python.

Objetivo da Prática:

- Compreender o processo de geração e armazenamento seguro de chaves criptográficas.
- Realizar a conversão de strings para bytes (encode/decode) necessária para operações criptográficas.
- Criptografar e descriptografar dados sensíveis em tempo de execução.

Tecnologias:

- Python 3
- Biblioteca: cryptography (módulo Fernet)

Aplicações Práticas (Blue Team / Defesa):
Essa lógica é a base para proteção de dados em repouso (Data at Rest) e na construção de gerenciadores de senhas seguros ou sistemas de mensageria interna confidencial.
